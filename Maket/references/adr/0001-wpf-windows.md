# ADR-0001: WPF для настольного клиента

Статус: принято 08.10.2026.

Контекст: заказчик уточнил, что рабочий клиент нужен только для Windows. Существующего C# проекта не было. Макет остаётся эталоном интерфейса.

Решение: WPF на .NET 8, архитектура MVVM, HTTP API Django. WPF позволяет сохранить плотные таблицы, клавиатурную работу и системное поведение Windows без кроссплатформенного слоя. Backend остаётся источником бизнес-правил.

Последствия: macOS не является целевой платформой production-клиента. Показ на MacBook относится только к ранее опубликованному веб-макету. Если позже потребуется macOS, это новая архитектурная задача, а не скрытое требование текущей сборки.
