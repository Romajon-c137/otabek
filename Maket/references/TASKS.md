MVP — минимальный складской/расчётный цикл, не завершение полного объёма. Для пользовательской MVP можно выполнить первые вертикальные шаги026 после019/025 (справочники, закупка, касса, возврат); всю026 нельзя помечать DONE до остальных шагов/024. Каждый вертикальный шаг026 отдельно проверяется и записывается в журнал. Платёж, API и UI выделены из проведения продажи. При блокировке платформы независимые backend задачи продолжаются.
