## Найдено во время исправления и проверки

- [x] 41. `server.js` createOnce: признак «уже создан» искался в тексте ответа (`"exists"`), которого в ответе по сети нет. Повтор после потерянного ответа навсегда падал в «не отправлено». Теперь признак — ошибка поля `id`.
- [x] 42. `backend` товары и контрагенты: повторное создание с тем же идентификатором давало 500 (IntegrityError). Программа считала это временным сбоем и бесконечно повторяла запрос — любое изменение человека или товара в рабочем режиме застревало в очереди. Теперь сервер отвечает понятной ошибкой поля `id`, программа обновляет запись. Есть тест.
- [x] 43. `server.js` запуск без связи: «розничный покупатель» был неизвестен, и продажа без человека отклонялась сервером. Теперь он запоминается, а пока неизвестен — действие ждёт в очереди.
- [x] A2 (сделано). Сервер с `DJANGO_DEBUG=false` не запускается со стандартным ключом-заглушкой.
