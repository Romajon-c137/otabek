# Жизненные циклы

## Учётные документы

`draft → posted → cancelled`

- Черновик разрешено редактировать с проверкой `version` или удалить; оба действия
  записываются в аудит.
- Проведение создаёт регистры и блокирует содержимое.
- Отмена проводится только отдельной командой и создаёт обратные движения.
- Удаление проведённых и отменённых документов запрещено.

## Заказ покупателя

`draft → confirmed (на сборке) → assembled → fulfilled`

Из любого активного этапа до выполнения возможен переход в `cancelled`. Из
`assembled` заказ можно вернуть на сборку. Подтверждение резервирует доступный
товар; выполнение создаёт продажу и снимает собственный резерв атомарно.

## Оплата

`posted → voided`

Оплата сразу проводится. Исправление выполняется отменой с обратным распределением.
