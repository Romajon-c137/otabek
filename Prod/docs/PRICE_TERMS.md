# Цена и условия строки продажи

## Назначение

Цена каждого размера в окне подбора является действием. Окно «Цена и условия»
позволяет задать цену продажи, скидку строки и отметить часть количества как
взятую у стороннего поставщика («соседа»).

## Контракт API

В строках `POST/PUT /api/v1/documents/` поддерживается необязательный объект:

```json
{
  "product_id": 123,
  "quantity": "3.000",
  "unit_price": "100.00",
  "discount_amount": "15.00",
  "neighbor_supply": {
    "supplier_id": 9,
    "quantity": "2.000",
    "unit_price": "60.00"
  }
}
```

Сервер проверяет, что контрагент активен и имеет тип `supplier`/`both`, количество
положительно и не превышает количество строки, а закупочная цена положительна.
Условия разрешены только для продажи и заказа покупателя.

## Учёт

- Условия хранятся в `documents.NeighborSupply`, а не в интерфейсном JSON.
- При проведении продажи сумма `quantity × unit_price` атомарно создаёт отдельное
  обязательство `payable` поставщику с привязкой к документу и товару.
- Из локального FIFO списывается только часть строки, не взятая у соседа.
- При выполнении заказа условия копируются в созданную продажу.
- При отмене продажи восстанавливается только локальная часть, а все связанные
  обязательства покупателя и поставщиков разворачиваются одной транзакцией.
- Финансовые движения остаются в `SettlementMovement`, существенные переходы
  документа — в неизменяемом журнале аудита и ленте синхронизации.
