| Импорт | Шаблон/проверка/применение | товары, контрагенты, партии и долги; весь пакет атомарно; повтор блокируется БД | `ImportBatch`, документы, обязательства | `/import/*` | owner/manager | import tests |
| Кассы | Получать изменения | строгий курсор, фильтр складов, long polling | `SyncCounter`, `ChangeEvent` | `/sync/state`, `/sync/changes` | доступ к складу | sync-feed test |

| Django Admin | Пользователи/права | регистры и аудит только для чтения | auth, grants, все ledgers | `/admin` | staff | system check |

## Поперечные гарантии

- Идемпотентность: проведение, отмена, подтверждение, выполнение, долг и оплата.
- Конкурентность: блокировки остатков, исходных строк возврата, партий, резервов,
  контрагентов и обязательств; PostgreSQL-тесты покрывают последнюю единицу,
  двойной возврат и встречный взаимозачёт.
- Оптимистическая блокировка черновика: поле `version`.
- Транзакционность: каждый бизнес-сценарий выполняется в `transaction.atomic`.
- Изоляция складов: выдача и отчёты ограничиваются `WarehouseGrant`.
- Масштабирование списков: документы, контрагенты, обязательства, оплаты и аудит
  используют серверную пагинацию с ограниченным размером страницы.
- Доступность с клавиатуры: стандартный Tab по интерактивным элементам, стрелки и
  Home/End по строкам таблиц, Enter запускает основное действие строки.
