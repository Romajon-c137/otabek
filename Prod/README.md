# ХозУчёт Production 2

Независимая production-реализация системы продаж, складского учёта и взаиморасчётов.
Исходный макет используется только как спецификация поведения и визуальный ориентир;
код приложения написан в этой папке заново.

## Структура

- `backend/` — Django/DRF, PostgreSQL, бизнес-операции и отчёты.
- `frontend/` — React + TypeScript + Vite.
- `docs/` — актуальные правила, архитектура и инструкция по эксплуатации.
- `tools/` — резервное копирование и восстановление данных.

Реализованы продажи и поступления со связанной оплатой, FIFO-партии, допрасходы,
скидки строк, заказы с резервом и печатью, возвраты по исходной
операции, долги/оплаты/взаимозачёт, отчёты, полный начальный XLSX-импорт, Otabek и
серверная лента изменений. Справочники и черновики редактируются через API;
системные записи защищены, а растущие списки используют серверную пагинацию и
поддерживают клавиатурную навигацию.
Главная касса использует компактную верхнюю навигацию,
итоги, быстрые операции и раздельные карточки задолженности.

Запуск и эксплуатация: `docs/OPERATIONS.md`. Архитектура и границы модулей:
`docs/ARCHITECTURE.md`. Карта функций и проверок: `docs/COVERAGE_MATRIX.md`.
